# ADC 安德鲁牙科连锁店诊疗管理系统

> 系统分析与设计 · 期末作业
> 信管 2401 · 1602240121 · 雷仁豪

一家 3 家门店的牙科连锁，从**预约挂号 → 到诊接诊 → 病历治疗 → 结算收款 → 耗材库存 → 排班调班 → 经营报表**的完整管理系统。

含三部分：**设计文档**（课程作业主体）、**可运行系统**（网页 + 小程序）、**验证记录**。

## 五、技术选型与约束

**后端零第三方依赖** —— 只用 Python 3.10+ 标准库：

- `http.server` 起 HTTP 服务（不装 Flask / FastAPI）
- `sqlite3` 本地库；云端切换到 MySQL（`db_mysql.py` 做方言适配）
- 模板用 f-string 拼 HTML，不引模板引擎
- 目的：**双击 run.bat 就能跑**，不给评阅者留装机器的麻烦

**小程序用微信原生**（不走 uni-app / Taro），36 个文件、10 个页面，请求走 `wx.cloud.callContainer`。
