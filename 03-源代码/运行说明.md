# 运行说明

## 一、最快方式：双击 `run.bat`

```
双击 run.bat  →  等它初始化数据（首次约 10 秒）  →  浏览器自动打开
```

然后访问 **http://127.0.0.1:8000**

`run.bat` 会做这几件事：

1. 找一个可用的 Python（`python` 或 `py -3`），检查版本 ≥ 3.10
2. 若 `data/adc.db` 不存在，先准备数据（首次约 20–30 秒）：
   - `app/server.py --init-only` —— 建表，并从 `app/seed_adc.db` 复制一份现成的演示库
   - `tools/seed.py` —— 门店、牙医、患者、预约、就诊、结算（主链路）
   - `tools/seed2.py` —— 耗材、采购、对账、质量、核算、排班流转
   - `tools/seed3.py` —— 待审批与投诉样例
3. 自动打开浏览器并启动服务

准备完的样子：**58 张表 / 11,802 行**，3 门店、10 位牙医、60 位患者、2,032 条预约、1,408 次就诊。

**关闭那个黑窗口即停止服务。**

想从头再来：把 `data/adc.db` 和 `rt/adc.db` 都删掉，再双击一次。

## 二、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（Linux / macOS 也可，用 `python app/server.py` 启动） |
| Python | **3.10 或更高** |
| 第三方依赖 | **无**。纯标准库：`http.server`、`sqlite3`、`json`、`hashlib` 等 |
| 数据库 | SQLite（随 Python 内置），文件在 `data/adc.db` |

装 Python 时记得勾选 **「Add Python to PATH」**。

## 三、手动启动（不想用 run.bat）

```bat
cd 03-源代码
python -X utf8 app\server.py --init-only     :: 首次：建表
python -X utf8 tools\seed.py                 :: 首次：灌主链路数据
python -X utf8 tools\seed2.py
python -X utf8 tools\seed3.py
python -X utf8 app\server.py                 :: 启动，监听 8000
```

换端口：

```bat
python -X utf8 app\server.py --port 8080
```

## 七、常见问题

**Q：双击 run.bat 一闪就没了**
命令行窗口里会有报错。手动打开 cmd，`cd` 到本目录，逐条执行 `run.bat` 里的命令看具体错误。

**Q：提示「没有找到 Python」**
没装 Python，或装的时候没勾「Add Python to PATH」。重装一次并勾选。

**Q：浏览器打开是空白 / 连接被拒绝**
服务没起来。看那个黑窗口里是否有 `ADC 诊疗管理系统  http://127.0.0.1:8000` 这行；没有就是启动失败。

**Q：端口 8000 被占用**
`python -X utf8 app\server.py --port 8080`，然后开 `http://127.0.0.1:8080`。

**Q：数据被我改乱了**
删掉 `data/adc.db`，重新双击 `run.bat` 会重新灌一份干净的。

## 八、云端部署（可选）

`Dockerfile` 已配好，容器听 80 端口：

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY . /app
ENV PORT=80
CMD ["python", "app/server.py", "--port", "80"]
```

部署到微信云托管时需在「服务设置 → 环境变量」里设置：

| 变量 | 值 | 作用 |
|---|---|---|
| `ADC_FORCE_SQLITE` | `1` | 强制用 SQLite，忽略平台自动注入的 MySQL 变量 |

> 不设这个变量时，云托管会自动注入 `MYSQL_ADDRESS` 等变量，程序会尝试连 MySQL 并在库不存在时报 401。设 `ADC_FORCE_SQLITE=1` 后直接走内置 SQLite，最省事。
